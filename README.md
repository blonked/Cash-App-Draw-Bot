🧩 Install the Extension (Unpacked / Developer Mode)

To install this extension manually, download and load it as an unpacked extension.

📥 Step 1: Download the files
Click the green Code button on this repository
Select Download ZIP
Extract the ZIP file to a folder on your computer

🌐 Step 2: Open Extensions Page
Chrome: chrome://extensions
Edge: edge://extensions

🛠️ Step 3: Enable Developer Mode
Toggle Developer mode (top-right corner of the page)

📂 Step 4: Load the Extension
Click Load unpacked
Select the extracted folder (the one containing manifest.json)
The extension will now be installed and ready to use
🔄 Updating the Extension


When updates are made:

Download and extract the new ZIP
Replace the old folder
Go to chrome://extensions
Click Reload on the extension card

⚠️ Important Notes
Do not move or delete the folder after loading it, or the extension will stop working
Always make sure manifest.json is in the root of the folder you select
